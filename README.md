# Minda Tenang

Laman web maklumat kesihatan mental dan bantuan kendiri untuk pesakit dan penjaga.

**Unit Psikiatri & Kesihatan Mental, Hospital Serian**

## Mengenai

- Laman statik, mesra telefon bimbit, dwibahasa (Bahasa Melayu + English)
- Dibuka melalui kod QR yang dicetak dalam buku temujanji pesakit
- Melengkapi, bukan menggantikan, rawatan klinikal
- Privasi sejak reka bentuk: tiada log masuk, tiada borang, tiada data pesakit dikumpul, tiada penjejak (tracker) pihak ketiga

## Struktur

```
index.html          Halaman utama (SPA ringkas, navigasi hash)
assets/style.css    Gaya
assets/app.js       Logik paparan, tukar bahasa, saiz teks, bacaan suara
assets/fonts/       Plus Jakarta Sans (SIL Open Font License 1.1)
content/ms.js       Kandungan Bahasa Melayu
content/en.js       Kandungan English
audio/              Ruang untuk rakaman suara latihan menenangkan diri
```

## Status

Versi draf (v0.3). Tag `noindex,nofollow` masih aktif dalam `index.html` —
laman boleh dibuka oleh sesiapa yang ada pautan atau kod QR, tetapi tidak
muncul dalam hasil carian Google. Tag itu dibuang selepas kelulusan Ketua
Jabatan.
